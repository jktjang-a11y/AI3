# 서술 작성 규칙 (공공기관 부동산 전문가 문체)

본 문서는 매달 서술 문단을 작성할 때 적용하는 고정 규칙이다. 동일 품질을 유지하기 위해 반드시 준수한다.

## 1. 종결어미 (단축형 분석 어조)
문장은 다음으로 마무리한다: `~됨`, `~확인됨`, `~판단됨`, `~분석됨`, `~견인함`, `~작용함`, `~형성됨`, `~유지됨`, `~관찰할 필요가 있음`.
- 단정이 어려운 사항은 `판단됨` / `분석됨` / `관찰할 필요가 있음`을 쓴다.

## 2. 금지어 → 대체어
| 금지(과장) 표현 | 대체 표현 |
|---|---|
| 압도적 | 가장 높은 |
| 미래 (잠재) 가치 선점 수요 | 향후 개발 기대를 반영한 수요 |
| 광역 자본의 전략적 포트폴리오 편입 | 광주권 자본의 자산 배분 및 매수세 유입 |
| 강한/강력한 하방 경직성 | 가격 하락이 제한되는 흐름 |
| 거래절벽 / 눈치보기 | 거래 소강 / 관망 기조 |
| 폭발적으로 | 크게 |
| 표준지 평가 | 조사 표본가격 / 조사 표본지 가격조사 |

## 3. 색상·강조 마크업 (render.py 내 함수)
- 상승/긍정: `R('텍스트')` (빨강 볼드)
- 하락/부정: `B('텍스트')` (파랑 볼드)
- 핵심 수치·지역·용도: `K('텍스트')` (순수 볼드)
- 색상 태그 안에는 마크다운 `**` 를 넣지 않는다.

## 4. 변동률 해석 원칙 (핵심)
- 지가변동률은 **조사 표본지 가격조사 결과**다. 표준지 평가가 아니다.
- 권역 `judge.플래그` 기준:
  - **실거래 주도**(거래 8건↑): "○○ 요인이 ○○면/동 지가 상승을 견인함."
  - **혼합**(4~7건): 거래·조사표본 병행으로 서술, 단일 고가거래는 일반화 한계 명시.
  - **조사표본 주도**(거래 0~3건): 상승 단정 금지. "○○ 입지/개발 기대가 조사 표본가격에 반영된 것으로 분석됨."

## 5. 권역별 서술 4단계 구조 (6장·9장)
지역 특성 → 수요 배경 → 당월 거래/개발 기대 → 지가 상승 사유 → 마무리 문장.
- 9장은 권역당 2~3문장으로 **압축**한다.
- 마무리 문장은 4번 원칙에 따른 표준 형식을 쓴다.

## 6. 개발사업·뉴스 서술 원칙
- 호재로만 쓰지 않는다. **추진 단계(구상/발표/예타/지구지정·고시/보상·착공/준공)와 실수요 유입 여부**를 함께 적는다.
- **철도 신설(경전선·광역철도·전철역 등) 등 확정성이 낮거나 혼동 가능성이 있는 사안은 제외**한다.
- 뉴스는 1차 소스(나주시청·전남도 보도자료, 국토부·LH 고시) 우선. 출처·시점을 명기한다.

## 7. 데이터 한계 고지 (10장 박스, 고정 유지)
- 월별 집계는 신고일자 기준. 데이터에 없는 월(예: 신고분 부재)은 추이에서 제외하고 각주.
- 인구이동(전입·전출) 미제공 시 인구·세대 증감만 제시.
- 매물-실거래 괴리율은 표본이 적으면 참고치로만 제시.
- 거래건수는 동일 계약(RTMS_KEY) 묶음 단위, 금액·면적은 합산.
