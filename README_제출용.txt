부동산 AI 동향 리포터 - 제출용 안내
===================================

1. 실행 방법
- `부동산 AI 동향 리포터.exe`를 더블클릭하면 실행됩니다. Python 설치는 필요 없습니다.
- 실행하면 EXE가 있는 폴더 아래에 `output` 폴더가 자동으로 만들어지고, 모든 결과가 그 안에 저장됩니다.
- 처음 실행 시 조사지역은 전남광주통합특별시 광산구, 조사기준월은 2026년 8월로 설정되어 있습니다.

2. 사용자가 입력할 항목
- 조사기준월(목록에서 선택), 시도, 시군구 세 가지뿐입니다. 빨간 글씨 항목이 필수입니다.
- KOSIS API 키, 법정동 코드, 출력 폴더는 프로그램에 내장되어 있어 따로 지정하지 않습니다.

3. 진행 순서
  ① 업무 탭(주간/월간/오피스텔)에서 필요한 통계를 선택하고 [선택 자료 수집 실행]
  ② 수집이 끝나면 자동으로 [1. 수집자료 점검] → [2. LLM 입력자료 생성]까지 진행됩니다.
     (수집 화면의 "수집 완료 후 자동 진행" 체크를 끄면 수동으로 진행합니다.)
  ③ [3. 프롬프트 TXT·LLM 사이트 열기] → 프롬프트가 클립보드에 복사되고 LLM 사이트가 열립니다.
  ④ 사이트 입력창에 Ctrl+V로 붙여넣어 실행합니다.
     ※ 필수 모델: 클로드 = Opus 5 이상 / GPT = 비슷한 수준의 최상위 모델 / 제미나이 = Pro
  ⑤ 결과 JSON을 복사해 [4. LLM JSON 반영]에 붙여넣으면 최종 HTML 보고서가 자동으로 열립니다.
  ⑥ [5. 최종 폴더 열기]를 누르면 최종 보고서 폴더가 열립니다.
- 단계 버튼은 실행한 단계가 파란 글씨, 앞으로 실행할 단계가 주황 글씨로 표시됩니다.

4. 결과물 저장 위치 (실행 폴더\output)
- 선택통계실행          : 수집한 원자료 엑셀
- 02_LLM입력자료\API기반 : data_pack, LLM 프롬프트 TXT, 1차 초안 HTML
- 03_LLM해설_JSON\API기반: LLM 해설 JSON
- 04_최종보고서\API기반  : 최종 HTML 보고서만 저장
                          (파일명: 업무명_시도_시군구_조사기준월_보고서.html)
- 99_검수자료\API기반    : 검수표 엑셀

5. 참고 사항
- 같은 지역·같은 조사기준월·같은 업무의 보고서를 다시 만들면 이전 산출물만 정리되고,
  다른 월·다른 업무·다른 지역 보고서는 그대로 보존됩니다.
- 설정은 `%APPDATA%\RealEstateApiReportUnified` 폴더에 저장됩니다.
- 공표 시차 때문에 조사기준월 자료가 아직 공표되지 않은 통계는 보고서에 "미공표"로 표시됩니다.

제작: 한국부동산원 장규태
