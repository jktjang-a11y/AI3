# 지가동향 보고서 스킬 — 매달 사용 안내

## 폴더 구조
```
land-price-report/
├─ SKILL.md                  # 스킬 정의·워크플로 (Claude가 읽음)
├─ README.md                 # 본 문서 (사람용 안내)
├─ scripts/
│  ├─ analyze.py             # 엑셀 → result.json (숫자 전수 분석, 재사용)
│  └─ render.py              # result.json → 보고서 HTML
└─ assets/
   └─ narrative_rules.md     # 서술 문체·금지어·구조 규칙 (매달 서술 시 적용)
```

## 매달 루틴 (약 10분)
1. **엑셀 업로드** — 실거래·지가동향·인구·세대·네이버매물(당월/전월) 엑셀을 업로드 폴더에 넣는다. 파일명에 키워드(실거래/지가동향/인구/세대/매물)만 들어 있으면 자동 인식된다.
2. **분석 실행** — `python scripts/analyze.py 2026-06`  → `result.json` 생성. (월 생략 시 최신 신고월 자동)
3. **서술 작성** — `result.json`을 근거로 `assets/narrative_rules.md` 규칙에 따라 권역 해석·뉴스·결론 문단을 작성하여 `render.py`의 해당 서술을 교체한다. (뉴스는 검색·사실확인)
4. **보고서 생성** — `python scripts/render.py result.json` → `{지역}_토지시장동향_시황보고서_{연}년{월}월.html` 생성.
5. **검증** — 서술 속 수치가 result.json과 일치하는지 대조한 뒤 공표 검토.

## 자동 / 수동 구분
- **자동(매달 그대로 재현):** 모든 표·차트·집계·증감·TOP10·판단근거표·인구표·매물표.
- **수동(매달 갱신):** 권역 해석·뉴스 3건·결론 등 서술 문단. → SKILL.md 3·4절 참조.

## 주의
- 지가변동률은 **조사 표본지 가격조사 결과**이며 실거래와 별개 지표다. 거래 희소 권역은 상승을 단정하지 않는다.
- 서술의 모든 수치는 result.json 값만 사용한다(임의 생성 금지).
- 최종 변동률 선정·공표는 담당자 책임이며, 본 스킬은 근거 정리·문서화를 돕는다.

## 다른 지역 확장
`scripts/analyze.py` 상단의 `REGION`, `ZONE_DEF`, `ZONE_TOKENS`를 해당 시·군에 맞게 수정하면 된다.
