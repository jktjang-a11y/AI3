# v5.8.38 수정 안내

## 핵심 수정
LLM 입력자료를 확장하고, 목포시 등 전남 시군구 보고서의 공급 파이프라인 필터를 시도 단위로 보정했습니다.

## 1. LLM 입력자료 확장
다음 5개 요약 자료가 LLM 프롬프트와 data_pack에 추가됩니다.

1) monthly_change_summary 확대
- 매매·전세·월세 전월 대비 거래건수 변화
- 상승·보합·하락 비율 변화
- 신규·갱신계약 건수
- 주요 읍면동, 상승·하락·상위 거래 사례

2) dong_focus_summary 추가
- 아파트 매매·전세·월세 상위 읍면동
- 비아파트 매매·전세·월세 상위 읍면동
- 지역특성과 연결할 수 있는 동 중심 분석 재료

3) case_focus_summary 추가
- 아파트 매매 상승·하락·거래금액 상위 사례
- 아파트 전세 상승·하락·보증금 상위 사례
- 아파트 월세 상승·하락·환산월세 상위 사례

4) non_apt_interpretation_summary 추가
- 비아파트 매매·전세·월세 거래건수
- 연립·다세대·단독·다가구 유형별 거래 집중도
- 거래건수 적을 때 방향성 단정 금지 문구

5) supply_pressure_summary 추가
- 인허가·착공·준공 최신값
- 전년 대비 변화
- 물건유형별 공급 흐름
- 시도 단위 공급통계 해석 기준

## 2. 목포시 공급 파이프라인 로직 보정
기존 v5.8.37은 공급 필터가 광주 행으로 고정되는 문제가 있었습니다.
v5.8.38에서는 조사지역이 전라남도 목포시, 무안군, 나주시 등인 경우 공급통계 필터를 전남/전라남도 행으로 자동 적용합니다.

## 3. LLM 분석 서술 강화
- 부동산원 해당지역 담당 조사 전문가 관점으로 프롬프트 보강
- 수치 나열보다 핵심 변화 → 원인 추정 → 관찰 포인트 구조로 작성
- 표·차트가 이미 보여주는 수치는 반복하지 않고 의미 해석 중심으로 작성
- 문장이 너무 길어지지 않도록 HTML/PDF 가독성 규칙 추가

## 4. HTML 디자인 가독성 보정
- 문단 줄간격과 word-break 보정
- A4 PDF 출력 시 문단 가독성 개선
- 카드·종합서술 박스 문장 흐름 보정
